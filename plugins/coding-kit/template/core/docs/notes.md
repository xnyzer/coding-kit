# Project notes

<!-- section:notes-head -->
Knowledge this project needs that has no other place in the repo — pitfalls, tool
quirks, facts about the environment that are safe to publish. `CLAUDE.md` imports this
file, so Claude Code loads it in every session; it travels with git, so it is the same on
every machine.

- **Projects without Graphiti write here.** With a Graphiti block in `CLAUDE.md`, such
  knowledge goes to the graph instead; this file stays and is still loaded.
- **One entry per topic:** a heading and two to four sentences. Replace an outdated
  entry instead of adding a new one.
- **Not here:** decisions and feature details (feature files, `docs/adr/`); private
  material such as hostnames, IPs or personal data (`private/`); a pointer per finished
  feature (`features/INDEX.md` is that pointer).
<!-- /section:notes-head -->
